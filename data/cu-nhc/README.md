# Cu–NHC data

Contains separate 3b syn and anti records, catalyst labels 3a–3e, IMes, IPr, retained map geometries, source yield values, and selected model outputs. The 3e, IMes, and IPr structures are constructed screening analogues as recorded in the source manifest. `energies.csv` is empty because per-geometry energies were not archived for these map inputs; use the retained population weights.
