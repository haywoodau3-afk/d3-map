# Fe porphyrin data

Contains Fe(TDCPP)Cl, Fe(TMP)Cl, and Fe(TPP)Cl inputs, retained aligned ensembles, sampling snapshots, stored weights, and field summaries. The model population is a fixed sextet GFN2-xTB electronic-energy ensemble at 298.15 K; it is not a Gibbs free-energy population. Energy-row to aligned-frame correspondence is not recorded in the exported descriptor table. See the root run manifest.
