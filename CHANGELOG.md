# Changelog

## 1.0.0rc1 — 2026-10-05

- Initial paper reproducibility package candidate assembled from the d3map research workspace.
- Added code, configuration, curated input and retained structures, numerical results, and source manifests for the Fe porphyrin, Cu–NHC, published Ru, Ru2 solvent-pilot, and Au–Cu studies.
- Retained rendered figures with a compact provenance manifest; omitted figure-generation code from the minimal package.
- Corrected the Fe energy table to use archived GFN2-xTB electronic energies; the energy-row to retained-frame join remains unrecorded.
- Recorded unreported author, affiliation, ORCID, repository URL, DOI, and per-run settings as unresolved metadata instead of inferring them.
